# GameSkool

Zwei Browser-Games für die Skool "September Comp" 2026: **Blitzableiter** und **Jack vs Slop**.
Mobile first, Canvas 2D, Vite + TypeScript, kein Backend.

- `/blitzableiter/` und `/jack-vs-slop/` sind eigenständige Einstiege.
- `src/kit/` ist der gemeinsame Unterbau (Loop, Input, Partikel, Sound, Storage).
- Design- und Research-Docs liegen in `docs/`.

```bash
npm install
npm run dev
npm test
npm run build
```
